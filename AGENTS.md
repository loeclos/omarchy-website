# AGENTS.md — omarchy-website

Landing site for Omarchy (DHH's Arch + Hyprland distro). TanStack Start (SSR)
+ Vite + React 19 + TypeScript + Tailwind CSS v4. Animations via `motion`
(`motion/react`), icons via `lucide-react`.

## Run / build (NixOS — no system node/npm!)

There is no `node` on PATH. Always go through nix-shell:

```bash
nix-shell --run 'npm run dev -- --port 3000'   # dev server (SSR)
nix-shell --run 'npm run build'                # production build
```

`shell.nix` provides `nodejs_22` (+ npm). Plain `npm run dev` without
nix-shell will fail with "command not found".

### Stray dev servers

Backgrounded `npm run dev` processes survive orphaned and squat on port 3000
(Vite then silently moves to 3001 — always check the actual port in output).
Find and kill by PID:

```bash
ps aux | grep '[v]ite dev'
kill <PID>...
```

Never `pkill -f 'vite dev'` — the pattern matches the shell running the
command itself.

## File map

```
src/
  router.tsx              # createRouter(routeTree) — rarely touched
  routeTree.gen.ts        # GENERATED by Start — never edit by hand
  styles.css              # Tailwind import, @theme tokens, keyframes, utilities
  routes/
    __root.tsx            # <html> shell, <head> (title, fonts), global providers
    index.tsx             # '/' landing page: hero + sections assembly
  components/
    Navbar.tsx            # pill nav + 3 dropdown menus (see below)
    Hero.tsx              # OmarchyHero + WordsPullUp / WordsPullUpMultiStyle
    Sections.tsx          # Marquee, Manifesto, Features, Install, Stats, Footer
    menus/
      ThemesMenu.tsx      # searchable theme list (swatches + style)
      NewsMenu.tsx        # searchable posts + NewsTitle (truncate/loop)
  hooks/
    useThemes.ts          # static THEMES array + query/expand state
    useNews.ts            # static POSTS array + query/expand state
```

`src/routes/*.tsx` are file-based routes (`createFileRoute('/')`).

## Navbar (`components/Navbar.tsx`) — read before touching

- Pill header (MANUAL link + OMARCHY / THEMES / NEWS `PillTrigger`s) is
  **static layout, never animated**. The ONLY animated width is the outer
  `motion.div`. Never put `layout` props on header/menu content or links will
  visually warp during animation.
- `openMenu: 'omarchy' | 'themes' | 'news' | null`:
  - `omarchy` → wide mega-menu (measured `menuW`), `MenuRow` links + big
    DOWNLOAD ISO CTA footer.
  - `themes` / `news` → exactly pill-width (`pillW`), searchable panels.
- Menu links are `{ label, href }` (`MenuLink`) with **real destinations**;
  external links get `target="_blank" rel="noreferrer"`. Pill triggers are
  toggle-only (`href="#"` + `preventDefault`); their old destinations live on
  in the panel footers (GitHub / Discord).
- Hover highlight state is a single `hovered: string | null` (label-keyed).
  `switchMenu` clears it; `scheduleClose` (150 ms, on container mouse-leave)
  also closes the menu and calls `themes.reset()` / `news.reset()`.
- `measure()` reads `headerRowRef` (pill) and `menuInnerRef` (mega-menu only);
  re-runs on `openMenu` change, resize, and `document.fonts.ready`.

## Menus & hooks

- `useThemes` / `useNews` own `query`, `expanded`, memo'd `filtered`,
  `visible` (capped at `PAGE_SIZE = 10`), `hasMore`, `reset`. Data is static
  arrays today — swap the array contents for a fetch later without changing
  consumers. Hooks are called in `Navbar` and passed as
  `ReturnType<typeof useThemes>` props.
- `>10` items → `Show more ->` / `Show less` toggle button. Lists are capped
  with `max-h-[46vh] overflow-y-auto`.
- `NewsMenu` rows: title, `line-clamp-2` description, tag chips, date.
  `NewsTitle` truncates with ellipsis; on hover it measures
  `scrollWidth > clientWidth` and only then swaps to the seamless
  duplicated-text loop (`.title-loop-track` + `@keyframes title-loop` in
  `styles.css`).
- Search inputs live inside the dropdown; the navbar root cancels the close
  timer on mouse-enter so typing doesn't collapse the menu.

## Styling conventions

- Theme tokens in `styles.css` (`@theme`): `font-lambda-mono` (JetBrains Mono,
  default nearly everywhere), `font-inter` (hero headline/body/button only),
  colors `lambda-bg/-line/-ink/-dim/-cream/-green/-pink`,
  `omarchy-cream #E1E0CC`, `omarchy-bg #060606`.
- Navbar root forces `uppercase` — prose-like text (inputs, descriptions,
  titles, empty states) must opt out with `normal-case tracking-normal`.
- `.noise-overlay` is an inline-SVG feTurbulence grain (no asset fetch).
- Pill + dropdown surfaces are pure `bg-black`; page bg is `#060606`.
- Fonts load via one Google Fonts `<link>` in `__root.tsx` head
  (Inter variable + JetBrains Mono). Add new families there, then expose a
  `--font-*` token in `@theme`.

## Verification

- `npm run build` passes but does **not** typecheck (esbuild). No lint script.
- Closed dropdowns render nothing server-side, so SSR HTML only proves the
  pill/hero. Verify menu content in the client bundle instead:

```bash
grep -o 'Search themes\.\.\.\|Show more\|<item>' dist/client/assets/routes-*.js | sort | uniq -c
```

- Fresh SSR check: start dev on a free port, `curl`/fetch `/`, assert 200 and
  key strings (title, pill labels, hero CTA).

## Gotchas

- `lucide-react@1.x` removed brand icons — there is no `Github` export
  (use `GitFork` or similar).
- Hero headline uses `whitespace-nowrap` with viewport-width font sizes tuned
  for 7-char "Omarchy" in its font; re-tune if the word or font changes, and
  keep descender clearance (`pb-[0.06em]` + wrapper padding).
- The hero `<section>` is `h-full` inside an `h-svh` padded wrapper in
  `index.tsx` — don't set the section itself to `h-svh` or padding overflows
  the viewport.
- Background video + poster live in `Hero.tsx`; menu link destinations in
  `Navbar.tsx` (`MENU`, `MANUAL_LINK`, panel footers) and the hooks' data
  arrays.
